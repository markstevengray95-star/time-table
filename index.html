How Smart Import protects accuracy

The parser uses multiple signals instead of assuming every school uses the same timetable format.

1. Reads layout

Weekday headings and time/period rows are detected using table structure or OCR coordinates.

2. Classifies cell content

Subject, class/group and room labels are separated using school-style patterns and aliases.

3. Requires review

Low-confidence fields are flagged so an OCR error never becomes a hidden timetable error.
